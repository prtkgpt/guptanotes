# Play Store listing assets

| File | Use in Play Console |
|---|---|
| `play-icon-512.png` | Store listing → App icon (512×512) |
| `feature-graphic.png` | Store listing → Feature graphic (1024×500) |
| `short-description.txt` | Short description (max 80 chars; current: 69) |
| `full-description.txt` | Full description (max 4000 chars) |

Still needed before the production listing: at least 2 phone screenshots —
take them on a device or emulator running the real build (portrait PNG/JPEG,
1080×1920 or similar).

The App Store (iOS) reuses the descriptions; its listing name must be
"Paperbark Notes" (exact-name conflict with an unrelated game), and it needs
its own screenshot sizes — see `../APP-STORE-SUBMISSION.md`.
